# Jupyter Notebooks

## Overview

This folder contains the Jupyter Notebook developed for the Hospital Management System Analysis project. It documents the end-to-end exploratory data analysis (EDA) process, from initial data inspection and preparation to analytical exploration and interpretation.

## Analysis Workflow

The notebook combines Python, Pandas, and SQL to:

- Inspect and understand the hospital dataset.
- Clean, validate, and prepare data for analysis.
- Query and examine hospital operational data using SQL.
- Analyze appointment activity and outcomes.
- Explore medical records and departmental staffing.
- Examine hospital bed resources and length-of-stay patterns.
- Identify key findings to support dashboard development.

## Tools & Technologies

- **Python** — Data analysis and scripting.
- **Pandas** — Data cleaning, manipulation, and analysis.
- **SQL** — Database querying and data exploration.
- **Jupyter Notebook** — Analytical workflow and documentation.

## Project File

`Hospital_Management_System_EDA.ipynb` — Contains the complete exploratory data analysis, code, and analytical findings used to develop the Power BI dashboard.
