# Dataset Documentation

This folder contains documentation for the dataset used in the Hospital Management System Analysis project.

## Dataset Source

The original dataset was obtained from Kaggle and provided in Excel/SQL format.

## Dataset Overview

The hospital management dataset contains information related to:

- Hospital departments
- Doctors, nurses, and helpers
- Patient appointments
- Medical records
- Hospital wards and beds
- Bed admission and discharge records

## Data Preparation

The dataset was reviewed, cleaned, validated, and prepared for exploratory data analysis using Python, Pandas, and SQL.

The analysis examined appointment outcomes, staffing distribution, medical records, and hospital bed resources.

## Data Availability

The original Excel workbook was retained locally and used as the source for the analysis. The processed data and analytical results are documented in the project notebook.
