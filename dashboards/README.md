# Hospital Management System Dashboard

## Overview

This folder contains the Power BI dashboard developed for the Hospital Management System Analysis project. The interactive report transforms hospital operational data into visual insights that support the examination of appointment activity, staffing distribution, medical records, and bed resources.

## Dashboard Pages

The report is organized into three interactive pages:

- **Hospital Overview** — Presents key hospital metrics, appointment outcomes, medical record activity, and department-level appointment distribution.
- **Appointment Performance** — Examines appointment outcomes and no-show rates across hospital departments to identify patterns in appointment activity.
- **Staffing & Resources** — Explores staffing distribution by department, listed beds by ward, average length of stay, and the relationship between admission volume and average stay duration.
